# Tests: DXF-Infrastruktur

Die Suite prüft Projekt- und Etagenroundtrips, AutoCAD-Struktur, Einheiten, Handles, Blöcke,
Layouts, aktuelle und ältere Metadaten, Sonderzeichen sowie Geometrie-Fallbacks. Beschädigte
Metadatensätze werden einzeln isoliert; gültige sichtbare Geometrie muss erhalten bleiben.
Atomisches Speichern wird mit bestehenden und fehlgeschlagenen Zielen geprüft.
