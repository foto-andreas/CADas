# Tests: Zeichnen und Bearbeiten

Diese Suite prüft Snap, Bemaßung, Auswahlpriorität, Wandbearbeitung, Transformationen und
Öffnungsplatzierung ohne JavaFX. Schwerpunkte sind Grenztoleranzen, gemeinsame Wandenden,
Kreuzungen, orthogonale Korrektur und unzulässige Öffnungen. Neue Zeichenalgorithmen benötigen
Tests für Standardfall, entartete Geometrie und den jeweils ersten Wert außerhalb der Toleranz.
