# Tests: DWG- und 3D-Fremdgeometrie

Die Tests sichern Konvertererkennung, Prozessdiagnosen, Einheiten, Blockanalyse sowie DXF-, SAT-,
IFC- und RFA-Geometrie ab. Testnetze enthalten konkave Konturen, Innenlöcher und beschädigte Daten.
Externe Prozesse werden mit Timeout, paralleler Ausgabe und nicht erfolgreichem Exit geprüft; echte
Systeminstallationen sind keine Voraussetzung für reproduzierbare Unit-Tests.
