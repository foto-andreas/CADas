# Tests: Berichte

Die Tests vergleichen Wohnfläche, Raumvolumen, Materialaggregation, Reststückoptimierung,
Markdown, HTML und PDF. PDF-Prüfungen validieren Signatur, Seitenzahl und extrahierten Fachtext.
Leere Projekte, Dachschrägen, Außenbalkone, gleichnamige unterschiedliche Materialien,
Heizelemente, Rasterbilder und atomische Zieldateien gehören zum Prüfumfang.
