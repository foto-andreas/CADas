# Tests: Flächenheizung

Diese umfangreiche Suite prüft Flächenzerlegung, Sperrflächen, maximale Rohrlänge, Meander,
Schnecke, Vario-Kommandos, Spiegelung, Rollenwechsel, Anschlussausrichtung und Wärmeleistung.
Konkave Räume und unroutebare Anschlüsse müssen zu erklärbaren Teilergebnissen oder Fehlern führen,
nicht zu kreuzenden oder außerhalb des Raums liegenden Rohrwegen.
