# Tests: Fachmodell

Diese Tests validieren Konstruktorinvarianten, IDs, Kopiermethoden, Host-Beziehungen, Wandprofile,
Raumdaten, Oberflächen, Heizung, Dach und Gelände. Jede neue persistierte Record-Komponente benötigt
zusätzlich einen Austausch-Roundtrip, damit Standardwerte älterer Dateien definiert bleiben.
